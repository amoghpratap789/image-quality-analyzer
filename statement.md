# Project Statement

## Project Title

Image Quality Analyzer Using Computer Vision

## Problem Statement

Digital images can have problems such as blur, incorrect brightness, and weak edge information. These problems can affect the usefulness of an image in Computer Vision applications.

The objective of this project is to develop a simple Computer Vision based system that analyzes an input image and provides an overall quality assessment.

## Scope of the Project

The project focuses on basic image quality analysis using Computer Vision techniques.

The system analyzes:

- Image sharpness
- Image brightness
- Edge information
- Overall image quality

The project is intended as a basic automated image quality assessment tool.

## Target Users

The system can be useful for:

- Students learning Computer Vision
- Developers working with image processing
- Users who want a basic image quality check
- Applications that require basic image preprocessing

## High-Level Features

1. Blur and sharpness detection
2. Brightness analysis
3. Edge detection
4. Quality score calculation
5. Quality recommendation
6. Input validation and error handling

## Input

The system accepts an image file in formats such as:

- JPG
- JPEG
- PNG

## Output

The system produces:

- Image resolution
- Blur score
- Blur classification
- Brightness value
- Brightness classification
- Edge density
- Overall quality score
- Quality recommendation

## Computer Vision Concepts Used

The project uses:

- Grayscale conversion
- Laplacian variance
- Canny edge detection
- Pixel intensity analysis
- Threshold-based classification
